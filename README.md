# Kura

一个原生的 macOS 素材管理应用，对标 [Eagle](https://eagle.cool)。用 Swift + SwiftUI 编写，不用 Electron。

> 名字取自日语“蔵”（kura）：存放珍贵物件的仓房。正式发布前还需要查商标。

## 第一版（0.1.0）能做什么

- **资源库**：新建、打开、在多个资源库之间切换；欢迎页列出最近打开的资源库
- **导入**：拖进窗口、拖到侧边栏文件夹、拖到 Dock 图标，或用工具栏 ＋ 选择文件。拖入的文件夹会变成同名的资源库文件夹
- **图片**：JPEG、PNG、GIF（预览会动）、HEIC、WebP、TIFF、PSD、SVG 等 ImageIO / Quick Look 能识别的格式
- **视频**：MP4、MOV、M4V 用系统播放器播放，支持逐帧、画中画，可以把当前帧设为封面
- **其他文件**：PDF、字体等交给 Quick Look 生成缩略图和预览
- **整理**：文件夹（可嵌套）、标签、评分、备注、来源链接；自动提取 5 个主色
- **浏览**：瀑布流网格、缩略图大小滑块、按类型筛选、排序、搜索（名称/标签/备注/链接）
- **预览**：图片双指缩放、双击切换 100%；底部胶片条；←/→ 切换，Esc 返回
- **废纸篓**：删除先进废纸篓，可恢复；清空时文件移到系统废纸篓
- **从 Eagle 迁移**：读取 `.library`，带过来文件夹结构、标签、备注、评分、来源和添加时间。只读，不改原资源库
- 深色模式、系统强调色跟随系统设置

### 快捷键

| 按键 | 作用 |
| --- | --- |
| 空格 / 回车 | 预览选中的素材 |
| ← / → | 在网格或预览里切换素材 |
| Esc | 退出预览 |
| ⌫ | 移到废纸篓（在废纸篓里是永久删除） |
| ⌘ 点击 / ⇧ 点击 | 多选 |
| ⌘A | 全选 |
| ⌘I | 导入文件 |
| ⌘O / ⇧⌘N | 打开 / 新建资源库 |

### 还没有做

- MKV、WebM、FLV、AVI 播放（计划接入 libmpv；目前会提示用其他应用打开）
- 浏览器扩展和快速收集面板
- 智能文件夹、随机漫游、按颜色筛选
- 全文索引（目前在内存里搜索，几千个素材内没有问题）
- 重复文件检测

## 构建

需要 macOS 14 以上和 Xcode 16 以上（Swift 6 工具链，按 Swift 5 语言模式编译）。没有第三方依赖。

```bash
scripts/build-app.sh          # 生成 build/Kura.app
open "build/Kura.app"
```

开发时也可以直接 `swift run`。重新生成应用图标：`swift scripts/make-icon.swift`。

## 资源库格式

资源库是一个 `.kura` 文件夹，可以放在 iCloud Drive、Dropbox 或 NAS 上同步：

```
我的素材.kura/
├── library.sqlite        # 素材、标签、文件夹等元数据
├── items/<id>/<原文件名>  # 原文件，导入时复制进来
└── thumbs/<id>.jpg|png   # 缩略图，最长边 720 像素
```

注意：同一个资源库不要在两台 Mac 上同时打开，SQLite 文件在同步盘上同时写入可能冲突。

## 代码结构

```
Sources/Kura/
├── App/        入口、菜单命令、资源库开关、文件面板
├── Library/    SQLite 封装、数据模型、导入、缩略图与颜色、Eagle 迁移
└── Views/      欢迎页、侧边栏、瀑布流网格、信息面板、预览
```
